descricao: anota por voz, organiza por seção e manda no zap na hora de sair
plano: S11

1. list_add (lista compras) com os itens que o senhor disser; a lista já se organiza por seção.
2. list_show para mostrar. "já comprei X" = list_check.
3. Na hora de sair, ofereça mandar a lista no WhatsApp para alguém: whatsapp_send (sempre pede sim).
