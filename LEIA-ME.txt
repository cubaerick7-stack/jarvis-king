JARVIS LITE V2

Essa versão corrige o problema em que o Qwen 1.7B escrevia:
    mute_audio mute
    search_files query="FO 1102"
mas não executava nada.

AGORA:
- volume, mute, arquivos, abrir programas, mídia etc. rodam direto no Python;
- o Qwen só é usado como fallback para pedidos mais difíceis;
- isso reduz bastante o uso de CPU.

PASSO A PASSO

1. Extraia o ZIP.

2. Copie:
   windows\jarvis_ai.py

para:
   G:\Jarvis\cozmo-esp32\windows\jarvis_ai.py

Substitua o anterior.

3. No PowerShell:

   G:
   cd G:\Jarvis\cozmo-esp32
   python -m pip install ollama pycaw pyautogui mss pypdf

4. Rode:

   python windows\jarvis_ai.py

OU, para iniciar o Ollama e o Jarvis juntos:
   powershell -ExecutionPolicy Bypass -File iniciar.ps1

TESTE:
   mn muta o volume
   desmuta
   coloca o volume em 50
   deixa o volume na metade
   qual o volume
   procura um pdf
   procura o arquivo FO 1102
   abre o primeiro
   procura o arquivo FO 1102
   mostra o primeiro na pasta
   abre a calculadora
   abre youtube

TESTES AUTOMATICOS
   python -m pip install pytest
   python -m pytest -q

Os testes simulam as acoes (nao mexem no volume nem abrem nada),
entao rodam em qualquer PC e tambem no GitHub a cada push.

LOG
Toda acao executada fica registrada em G:\Jarvis\logs\acoes.log
(horario, acao e detalhe), inclusive as escolhidas pelo Qwen.

O QUE O JARVIS SABE FAZER
Digite "o que voce sabe fazer" (ou "ajuda") com o Jarvis aberto.

ROTINAS
"modo estudo", "modo relaxar" e "modo foco" ja vem prontas.
Para criar as suas, crie G:\Jarvis\config\rotinas.json assim:

{
  "jogo": [
    {"name": "set_volume", "args": {"percent": 70}},
    {"name": "close_app", "args": {"name": "chrome"}},
    {"name": "open_target", "args": {"target": "omori"}}
  ]
}

e diga "modo jogo". Os nomes das acoes sao os da lista TOOLS.

COMO CRIAR UMA FERRAMENTA NOVA
1. Escreva a funcao em windows\ferramentas.py. Ela imprime o resultado
   e devolve True (deu certo) ou False (falhou).
2. Adicione uma entrada em TOOLS (windows\jarvis_ai.py):
   {"name": "minha_ferramenta", "args": '{"x":"..."}', "group": "sistema",
    "desc": "o que ela faz", "examples": ["como o usuario pede"],
    "run": lambda a: F.minha_ferramenta(a.get("x", ""))},
   So isso ja coloca ela no prompt do Qwen e na ajuda.
3. (Opcional) Para responder sem IA, adicione uma regra em
   fast_local_router chamando tool("minha_ferramenta", x=...).
4. Adicione um teste em tests\ e rode python -m pytest -q.

IA NA NUVEM (GEMINI)
Com a chave configurada, o Jarvis pensa com o Gemini (rapido, sem pesar a CPU)
e usa o Qwen local so se a nuvem falhar ou a internet cair.
1. No PowerShell (uma vez so):
   setx GEMINI_API_KEY "sua-chave"
2. Feche e abra o PowerShell de novo.
Opcional:
   setx JARVIS_NUVEM reserva     (Qwen primeiro, Gemini so se falhar)
   setx JARVIS_NUVEM desligada   (100% local)
   setx GEMINI_MODEL gemini-3.8-flash   (escolher o modelo)
A chave NUNCA vai para arquivo nem para o GitHub.
